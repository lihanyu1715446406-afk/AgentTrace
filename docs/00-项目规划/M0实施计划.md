# M0 实施计划：项目初始化与架构设计

> 依据：v2.0 第十九章 M0。**本文件是 M0 的落地步骤，确认后执行。**

## 1. 目标

建好可运行、可测试、可扩展的项目骨架，为 M1~M8 打地基。**不写业务代码。**

## 2. 步骤

| 步骤 | 内容 | 产出 |
|---|---|---|
| 1 | 用 uv 初始化项目 + 锁定 Python 3.12.14 | `pyproject.toml`、`.python-version` |
| 2 | 建 backend 包结构 + `main.py` 最小 FastAPI 应用（healthcheck） | `backend/app/` 可 import |
| 3 | 配置 `core/config.py`（pydantic-settings，读 `.env`）、`logging.py`、`exceptions.py` | 配置/日志/异常基建 |
| 4 | 安装核心依赖（fastapi/uvicorn/pydantic/sqlalchemy/alembic/langgraph/langchain/langchain-openai） | `uv.lock` |
| 5 | 配置 Alembic + 初始 migration（Project/Trace/Span/TokenUsage/DiagnosticTask/Finding/KnowledgeDocument/MemoryRecord） | `backend/alembic/` |
| 6 | 配置 Docker Compose：PostgreSQL（首期） | `docker-compose.yml` |
| 7 | 配置 pytest + 第一个冒烟测试（app 启动、healthcheck、DB 连接） | `backend/tests/` |
| 8 | 配置代码规范（ruff + mypy/类型注解）+ pre-commit | 质量基线 |
| 9 | 建 `.env.example` / `.gitignore` / 根 `README.md` | 工程约定 |
| 10 | 建 SDK / mcp_server / frontend 占位包结构 | 目录就绪 |

## 3. 交付物

- 可启动的 FastAPI 骨架（`/health` 返回 ok）。
- 可连通的 PostgreSQL（Docker Compose）。
- 可执行的 Alembic 迁移。
- 可运行的 pytest 冒烟测试。
- `uv.lock` 锁定依赖版本。
- 代码规范与 pre-commit 生效。

## 4. 验收标准

- [ ] `uv run uvicorn backend.app.main:app` 可启动。
- [ ] `GET /health` 返回 200。
- [ ] `uv run pytest` 全绿。
- [ ] `alembic upgrade head` 成功建表。
- [ ] Docker Compose 能起 PostgreSQL。

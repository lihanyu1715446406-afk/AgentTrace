## 关键难点专项说明

1. **Agent 输出确定性**：LLM 输出天然非确定，工程上用「结构化输出 + schema 校验 + 有限重试」把不确定性收敛到可控范围，而不是假设 LLM 一定返回合法 JSON。
2. **诊断结果可溯源**：每个 Finding 必须带 evidence 指向具体 Trace/Span（v2.0 5.5），这是与「LLM 自由发挥」的本质区别。
3. **多 Agent 结果矛盾处理**：保留各自证据 → 核对数据来源 → 触发补充分析 → 仍无法确定则明确报告不确定性（v2.0 9.4）。
4. **反思防死循环**：限制反思次数与最大执行时间，反思必须结合证据而非让模型空转（v2.0 12.3）。

# 开发路线图（里程碑）

> 依据：v2.0 第十九章。**严格按里程碑推进，禁止一次性生成全部代码。**
> 每个里程碑必须：明确目标 → 技术方案 → 实现功能 → 写测试 → 检查质量 → 验证可用 → 更新学习文档 → 更新进度，全部通过才进入下一里程碑。

## 里程碑总览

| 里程碑 | 主题 | 核心交付 | 学习文档 |
|---|---|---|---|
| M0 | 项目初始化与架构 | 骨架/环境/CI/DB 迁移/架构文档 | 01-Python基础（起步） |
| M1 | 单 Agent + Tool Calling | LLM 接入 + ReAct Agent + 工具 | 02-Agent基础 / 03-Tool-Calling |
| M2 | Planning | 意图分析 + 计划生成 + 条件路由 | 04-Planning |
| M3 | Multi-Agent | Supervisor + 4 专业 Agent + 汇总 | 05-Multi-Agent |
| M4 | RAG | 文档解析/切分/Embedding/Qdrant/检索 | 06-RAG |
| M5 | Memory | Checkpointer + 长期记忆 | 07-Memory |
| M6 | Reflection + Evaluation | 证据检查 + 测试集评估 | 08-Reflection / 09-Evaluation |

| M8 | MCP + 工程化 | MCP Server + Dashboard + Docker | 11-MCP / 12-工程化 / 13-源码解析 |

## 各里程碑详情

### M0 项目初始化与架构设计
- **开发**：建项目、配 Python 环境（uv + 3.12）、目录结构、代码规范、测试环境、Docker Compose、架构/数据库文档。
- **学习**：Python 项目管理、虚拟环境、模块化设计、FastAPI 基础、Docker 基础。
- **验收**：项目能启动、基础测试通过。

### M1 单 Agent 与 Tool Calling
- **开发**：接 LLM、基础 Agent、TraceQueryTool / SpanQueryTool / CostAnalysisTool、工具注册、工具调用记录。
- **学习**：LLM 基础、Prompt、Function Calling、Agent Loop、ReAct、LangChain Tool。
- **验收**：用户提问后 Agent 自主选工具、取真实数据并回答。

### M2 Planning
- **开发**：Intent Analyzer、Task Planner、结构化计划、条件路由、任务状态管理、有限重规划。
- **学习**：Planning、ReAct、Plan-and-Execute、LangGraph State、Conditional Edges。
- **验收**：不同任务生成不同计划并按计划执行。

### M3 Multi-Agent
- **开发**：Supervisor、Trace/Error/Cost Analyzer、Report Agent、顺序+并行协作、结果汇总。
- **学习**：Multi-Agent、Supervisor、Subagent、State Sharing、Parallel Execution、Routing。
- **验收**：一次综合诊断调用多个专业 Agent 并产出统一报告。

### M4 RAG
- **开发**：文档上传、解析、切分、Embedding、Qdrant、向量检索、Metadata Filtering、检索工具。
- **学习**：RAG 原理、Embedding、向量库、Chunking、相似度检索。
- **验收**：Agent 检索知识库辅助诊断，回答保留来源。

### M5 Memory
- **开发**：Checkpointer、Working/Episodic/Semantic Memory、检索/更新/巩固。
- **学习**：Agent Memory、短/长期记忆、Checkpointer、Store。
- **验收**：能恢复中断任务，并在新任务中检索历史经历。

### M6 Reflection 与 Evaluation
- **开发**：证据检查、一致性检查、有限重分析、标准测试集、自动化评估、评估报告。
- **学习**：Reflection、Self-Correction、Agent Evaluation、LLM-as-a-Judge。
- **验收**：能识别缺证据的结论，并能用测试集评估效果。

### M7 SDK 与数据采集
- **开发**：Python SDK、Trace/Span 管理、父子关系、Token 记录、异步上报、LangGraph 集成。
- **学习**：SDK 设计、Context Manager、Decorator、Asyncio、采集。
- **验收**：外部 Python Agent 接入后，系统能采集并展示真实数据。

### M8 MCP 与工程化
- **开发**：MCP Server、MCP Tools、REST API 完善、鉴权、React Dashboard、Docker、集成测试、README。
- **学习**：MCP、FastAPI、React、RESTful、Docker、工程化。
- **验收**：MCP Client 可调用工具，Docker Compose 一键部署运行。

## 依赖关系

```
M0 → M1 → M2 → M3 → M6 → M8
                ↘
M0 → M4 → M5 ↗
M0 → M7 ↗
```

- M1/M2/M3/M6 是 Agent 能力主线，强依赖。
- M4/M5 依赖 M0 与基础 Agent 能力，可与主线并行。
- M7（SDK）依赖 M0，可较早并行。
- M8 收尾整合。
